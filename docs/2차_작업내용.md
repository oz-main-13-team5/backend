# 2차 작업 내용

## 완료한 작업
- 북마크 API에 **중복 방지**(`409`)와 **20개 제한** 응답(`success: false`) 추가
- 마이페이지용 Serializer/View/URL 구성 (`/me` GET, PATCH)
- 북마크·마이페이지 단위 테스트 통과 (`python3 manage.py test apps.bookmarks.tests apps.mypage.tests`)
- 프로젝트 README를 최신 엔드포인트 정보에 맞춰 갱신

## 구현 메모
- `BookmarkView.post`에서 저장 전 개수와 중복을 체크하도록 순서 조정
- `UserProfileUpdateSerializer`는 닉네임/비밀번호 중 최소 1개 필수, 닉네임 중복 검사 포함
- `UserProfileView.patch`는 수정된 필드를 `updated_fields` 배열로 반환
